# Keduly

A calendar and task manager built for working with AI agents.

- **Projects** organise everything: a project is both a list of items and a calendar colour.
- **One timeline**: events and the time blocks of your items share the same calendar.
- **Agents propose, you decide**: an agent can read and write through the CLI, but its scheduling
  suggestions appear as tentative entries that take effect only when you accept them. Every change
  is logged with who made it and why, and can be undone.
- **Works with the calendar apps you already use** through CalDAV.

Status: under active development.
